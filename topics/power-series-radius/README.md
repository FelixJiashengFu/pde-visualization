## 命题

若 `lim a_{n+1}/a_n = l` 存在，则

```text
Σ a_n z^n,    Σ a_n z^{n+1}/(n+1),    Σ n a_n z^{n-1}
```

有相同的收敛半径 `R = 1/|l|`（`l = 0` 时 `R = ∞`）。

## 证明思路

1. 对固定的 `z ≠ 0`，原级数相邻两项的模之比趋于 `|l||z|`。由比值判别法，`|l||z| < 1` 时绝对收敛，`|l||z| > 1` 时通项不趋于 0 而发散，故 `R = 1/|l|`。
2. 记 `b_n = a_n/(n+1)`、`c_n = n a_n`。提出或除去一个 `z` 不改变敛散，而 `b_{n+1}/b_n = (a_{n+1}/a_n)·(n+1)/(n+2) → l`，`c_{n+1}/c_n = (a_{n+1}/a_n)·(n+1)/n → l`。
3. 三个级数的系数之比有同一极限，由第 1 步，收敛半径相同。

页面的“余论”另外说明三点：圆周上三者的敛散可以不同；后两个级数是原级数的逐项积分与逐项求导；去掉题设条件后结论仍成立（柯西–阿达马公式加 `n^{1/n} → 1`）。

## 验证与范围

运行 `node source/verify.cjs`，共 27 项检查：三组系数的比值公式与 `ln|a_n|` 一致，三个级数的系数之比在 `n = 10^6` 处接近 `l`，圆内通项趋于 0，圆外通项无界。

三步证明是严格的。两幅图是三组具体系数的数值示意，不构成证明；图二右只画通项大小，通项趋于 0 本身不能推出收敛，圆内的收敛性由比值判别法保证。圆周上的情形页面只给文字说明，没有画图。
