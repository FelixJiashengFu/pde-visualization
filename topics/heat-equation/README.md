# 热方程：分离变量 · 热核 · 差分稳定性

**分类：**抛物型 · 热与扩散。同一个方程 `u_t = k u_xx` 的三种看法：有界杆上的模态衰减、无穷直线上的热核卷积、显式差分格式的稳定性条件。

## 方程、区域和初边值条件

| 实验 | 区域与条件 | 解法 |
| --- | --- | --- |
| 一 · 分离变量 | `0<x<1`，`u(x,0)=φ(x)`；Dirichlet `u(0,t)=u(1,t)=0` 或 Neumann `u_x=0` | `u = Σ bₙ e^{−n²π²kt} sin(nπx)`（Neumann 为余弦级数加常数项 `a₀`） |
| 二 · 热核 | `x∈ℝ`，初值为方块、阶跃、两块或高斯 | `u = S * φ`，`S(z,t)=e^{−z²/4kt}/√(4πkt)`；方块给出误差函数闭式 |
| 三 · 差分 | `[0,1]`，`u=0` 边界，`k=1` | FTCS：`u_j^{n+1}=u_j^n+r(u_{j+1}^n−2u_j^n+u_{j−1}^n)`，`r=kΔt/Δx²` |

## 验证与范围

运行 `node source/verify.cjs`，共 15 项检查：误差函数精度、正弦系数与闭式一致、边界条件、方程残差、Neumann 热量守恒、热核闭式与数值卷积一致（差 < 2×10⁻⁸）、无穷传播速度、最大值原理单调性、直线上热量守恒、FTCS 放大因子、`r=0.4` 收敛、`r=0.5` 离散最大值原理、`r=0.6` 爆炸。

级数解、热核公式与 `G(θ)` 是精确结论；页面画的是有限项部分和、误差函数逼近式（相对误差 < 1.2×10⁻⁷）与离散采样。页面已用无头 Chromium 在 `file://` 下截图检查（桌面 1300 px 与手机 390 px 宽度，无脚本错误、无横向溢出）。
