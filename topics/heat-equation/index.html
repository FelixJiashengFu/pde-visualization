Heat equation · 抛物型 · 热与扩散

热方程：
温度如何被慢慢抹平

同一个方程 ut = k uxx，三种看法：在有界杆上把初温分解成正弦模态、各自指数衰减；在无穷直线上把初温与高斯热核做卷积；在计算机上用显式差分一步步推进，并看清它何时会“炸”。

Problem

方程、初边值条件与三条结论

有界杆上的初边值问题

ut = k uxx,  0<x<1,  t>0;   u(x,0)=φ(x)

读法：“u 对 t 的偏导等于 k 乘 u 对 x 的二阶偏导”。u(x,t) 是位置 x、时刻 t 的温度；k>0 是热扩散系数；φ 是初始温度分布。

Dirichlet：u(0,t)=u(1,t)=0  |  Neumann：ux(0,t)=ux(1,t)=0

Dirichlet 表示两端浸在 0 度的恒温槽里；Neumann 表示两端绝热、没有热流穿过。

分离变量给出的级数解（Dirichlet）

u(x,t) = Σn≥1 bn e−n²π²kt sin(nπx),   bn = 2∫01 φ(x) sin(nπx) dx

bn 是初温的第 n 个正弦系数；e−n²π²kt 是第 n 个模态的衰减因子，衰减率与 n² 成正比。Neumann 情形把 sin 换成 cos，并多出不衰减的平均温度 a0=∫φ。

结论 1（平滑化）：只要 t>0，高频模态被 e−n²π²kt 压得极快，所以 u(·,t) 是光滑函数——即使 φ 有跳跃。

无穷直线上的热核公式

u(x,t) = ∫−∞∞ S(x−y,t) φ(y) dy,   S(z,t) = 1√(4πkt) e−z²/(4kt)

S 叫热核（基本解），是方差为 2kt 的高斯密度：∫S dz = 1。读作“u 在 x 处的值是初温以 S 为权重的加权平均”。

结论 2（无穷传播速度）：只要 φ≥0 且不恒为零，任意 t>0 时所有 x 处都有 u(x,t)>0——热“瞬间”传到无穷远，只是极其微弱。

最大值原理与数值稳定性

max[0,1]×[0,T] u = max{ 初值的最大值, 边界值的最大值 }

弱最大值原理：热方程的解不会在内部“自己升温”，最大值只出现在初始时刻或边界上。它直接推出解的唯一性和对初值的稳定性。

显式差分稳定 ⇔ r = kΔtΔx² ≤ 12
结论 3（离散最大值原理）：r ≤ ½ 时新值是旧值的凸组合，离散解同样服从最大值原理；r > ½ 时最高频的锯齿模态每步被放大 |1−4r| 倍。

Derivation

从方程到图：六步推导

1

分离变量

设 u = X(x)T(t)，代入得 T′/(kT) = X″/X。左边只依赖 t、右边只依赖 x，所以两边等于同一常数 −λ：X″ + λX = 0，T′ = −λkT。

2

边界决定特征值

X(0)=X(1)=0 只允许 λn = n²π²、Xn = sin(nπx)（n=1,2,…）；绝热边界 X′(0)=X′(1)=0 给出 Xn = cos(nπx)，并多出 λ0=0 的常数模态。对应 Tn = e−n²π²kt。

3

叠加并用正交性定系数

线性方程允许叠加。令 t=0 与 φ 相等，两边乘 sin(mπx) 积分，由 ∫01 sin(nπx)sin(mπx)dx = ½δnm 得 bm = 2∫φ sin(mπx)dx。实验一的谱图画的就是这些数乘上衰减因子。

4

直线上：卷积与热核

在 ℝ 上没有边界、模态变成连续的傅里叶变换：û(ξ,t) = e−kξ²t φ̂(ξ)。e−kξ²t 的逆变换正是高斯 S(x,t)，乘积变卷积，得到 u = S * φ。方块初值代入后得 u = ½[erf((1−x)/√(4kt)) + erf((1+x)/√(4kt))]，实验二用的就是这个闭式。

5

最大值原理

若 u 在内部某点达到严格大于边界与初值的最大值，那里 uxx ≤ 0、ut ≥ 0；用 v = u + εx² 把不等式变严格即可得出矛盾。推论：两个解之差满足零初边值，所以恒为零——解唯一。实验二的金线（max u）随时间单调不增，正是它的体现。

6

差分格式的 von Neumann 分析

把 ujn = Gneijθ 代入 FTCS 格式，得 G = 1 − 4r sin²(θ/2)。θ=π（相邻格点正负交替的锯齿）时 G = 1−4r，|G| ≤ 1 ⇔ r ≤ ½。r ≤ ½ 时新值 = r·左 + (1−2r)·中 + r·右，三个系数非负、和为 1，所以离散最大值原理成立。

Scope

限制与小结

  • 精确 vs 近似：级数解、热核公式和 G(θ) 是精确结论；实验一画的是 N 项部分和（系数用 4000 点中点公式计算），实验二的误差函数用相对误差 <1.2×10⁻⁷ 的逼近式，实验三的“精确解”是 200 项级数。
  • t = 0 处的 Gibbs 振荡：方块等含跳跃的初值，其部分和在 t=0 有约 9% 的过冲，这是傅里叶级数本身的现象，并非热方程的解。任意 t>0 后振荡迅速消失。
  • “常数 1 + Dirichlet”：初值与边界在端点不相容，级数在端点处收敛到 0 而不是 1；但对每个 t>0，解仍光滑且满足边界条件。
  • 无穷传播速度是此模型（Fourier 导热定律）的数学性质；真实材料中极远处温度低于任何测量精度。读数里极小的正数仅说明 u>0，其具体数值受逼近式精度限制。
  • 差分稳定性只演示了一维、常系数、Dirichlet 边界的 FTCS 格式；隐式格式（如 Crank–Nicolson）对任意 r 都稳定，本页未展示。
一句话：热方程把高频成分以 e−n²π²kt 的速度抹掉——这同时解释了解的光滑化、最大值原理（不会产生新的峰），以及为什么显式格式必须用 Δt ∝ Δx² 的小步长。
