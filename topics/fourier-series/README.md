# 傅里叶级数：部分和、Gibbs 现象与系数衰减

**分类：**分析工具 · 级数与收敛。分离变量法的解都是傅里叶级数；本专题看部分和如何逼近函数、跳跃处约 8.95% 的 Gibbs 超调、Fejér 平均如何消除它，以及系数衰减速度与（延拓后）函数光滑性的关系。

- [打开单文件交互页](index.html)；纯原生 JavaScript + Canvas，无外部依赖，可离线打开。
- [验证脚本说明](source/README.md)。
- [返回 PDE 专题目录](../../index.html)。

## 内容

| 级数 | 区间 | 延拓 | 对应的 PDE 边界 |
| --- | --- | --- | --- |
| 完整级数 `a₀/2+Σ(aₙcos nx+bₙsin nx)` | `(−π,π)` | 2π 周期 | 周期边界 |
| 正弦级数 `Σbₙ sin nx` | `(0,π)` | 奇延拓 | Dirichlet |
| 余弦级数 `a₀/2+Σaₙ cos nx` | `(0,π)` | 偶延拓 | Neumann |

预设函数：方波 `sgn x`、锯齿 `x`、`|x|`、`x²`、半波整流、光滑 `e^{cos x}`，也可手绘。

## 验证与范围

运行 `node source/verify.cjs`，共 13 项检查：锯齿、`x²`、方波、`|x|`、`x²` 正弦级数的系数闭式，`e^{cos x}` 系数等于 `2Iₙ(1)`，方波 `N=400` 超调 0.0895，Fejér 平均无超调，跳跃点收敛到平均值，连续点收敛，L² 范数，Parseval 和，奇／偶延拓。

系数用中点公式加 Richardson 外推计算；超调、最大误差是在采样点上读取的数值近似。页面已用无头 Chromium 在 `file://` 下截图检查（桌面与手机宽度，无脚本错误、无横向溢出）。
