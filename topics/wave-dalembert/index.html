波动方程：
d'Alembert 公式与特征线

一维波动方程 utt = c²uxx 的解可以完全写出来：两列形状不变、以速度 c 反向奔跑的行波之和。本页把这件事拆开看——行波分解、特征线上的依赖域与影响域，以及有限弦端点处的“镜像反射”和能量守恒。

Problem

方程、初值条件与三条结论

无界弦的 Cauchy 问题

utt = c² uxx,  x ∈ ℝ, t>0;   u(x,0)=φ(x),  ut(x,0)=ψ(x)

u(x,t) 是弦在位置 x、时刻 t 的横向位移；c>0 是波速；φ 是初始形状，ψ 是初始速度（比如用锤子敲一下给的冲量）。需要两个初值，因为方程对 t 是二阶的。

u(x,t) = ½[φ(x−ct) + φ(x+ct)] + 12c∫x−ctx+ct ψ(s) ds

这就是 d'Alembert 公式。φ(x−ct) 是把 φ 的图像整体向右平移 ct，φ(x+ct) 向左平移 ct。

三条结论

结论 1（行波分解）：初始形状一分为二，各带一半高度，分别以速度 c 向左右跑，形状保持不变。
结论 2（有限传播速度）：u(x₀,t₀) 只依赖区间 [x₀−ct₀, x₀+ct₀] 上的初值——这是 (x₀,t₀) 的依赖域，由两条特征线 x ± ct = 常数 围成。与热方程的“无穷传播速度”形成对照。
结论 3（能量守恒与反射）：E(t) = ½∫(ut² + c²ux²)dx 不随时间变化。在固定端（u=0），脉冲反射后上下翻转；在自由端（ux=0），反射后不翻转。

Derivation

从方程到图：六步推导

1

算子分解

utt − c²uxx = (∂t − c∂x)(∂t + c∂x)u = 0。每个一阶因子都是沿某个方向的方向导数。

2

特征坐标

令 ξ = x + ct、η = x − ct，方程变为 uξη = 0，所以 u = F(ξ) + G(η) = F(x+ct) + G(x−ct)：一列左行波加一列右行波。直线 ξ = 常数、η = 常数 就是特征线。

3

用初值定 F、G

t=0：F + G = φ，c(F′ − G′) = ψ。积分第二式得 F − G = (1/c)∫0xψ + 常数，与第一式联立解出 F、G，代回即得 d'Alembert 公式。

4

依赖域与影响域

公式中只出现 φ 在 x₀ ± ct₀ 两点的值和 ψ 在 [x₀−ct₀, x₀+ct₀] 上的积分，所以 u(x₀,t₀) 不受区间外初值影响。反过来，初值支集 [a,b] 只能影响 a − ct ≤ x ≤ b + ct 的楔形区域。φ 的跳跃或尖角沿特征线原样传播，不会被抹平——这与热方程截然不同。

5

端点反射 = 镜像

固定端 u(0,t)=0：把 φ、ψ 奇延拓到 x<0，d'Alembert 解自动满足 u(0,t)=½[φ(−ct)+φ(ct)]+… = 0。两端都固定则做 2L 周期奇延拓。自由端 ux=0 对应偶延拓。镜像脉冲穿过端点进入弦内，看起来就是“反射”；奇延拓带负号，所以反射后翻转。

6

能量守恒

方程两边乘 ut：(½ut² + ½c²ux²)t = (c²utux)x。在 [0,L] 上积分，右边只剩边界项 c²utux|0L；固定端 ut=0、自由端 ux=0，都让它为零，所以 dE/dt = 0。能量守恒还推出解的唯一性。

Scope

限制与小结

  • 精确 vs 近似：所有曲线都由 d'Alembert 公式逐点精确计算；高斯冲量的原函数用误差函数（逼近式相对误差 <1.2×10⁻⁷）。能量积分用 800 点中点公式，读数里 10⁻¹⁰ 量级以下的漂移是数值积分误差。
  • 方块、三角初值不是经典 C² 解：d'Alembert 公式给出的是弱解（广义解），跳跃和尖角沿特征线传播。实验三只用光滑高斯脉冲，因为跳跃初值的能量为无穷大。
  • 实验三的初值是高斯脉冲的镜像和，它在端点处严格满足边界条件；在 [0,L] 内与单个高斯的差别小于 e−(0.8/0.4)² ≈ 0.018（最坏参数）而通常远小于此。
  • 自由端 + 速度冲量：两端自由时总动量守恒且不为零，弦会整体漂移（u 的平均值线性增长），这是模型的正确行为，不是数值误差。
  • 本页只讨论一维、常系数、无阻尼的情形。带摩擦的弦见本库的“受摩擦阻尼的弦”专题；高维波动方程的 Huygens 原理（三维中依赖域只是球面）本页未涉及。
一句话：波动方程的一切都写在两族特征线 x ± ct = 常数 上：信息沿它们以有限速度 c 传播、奇点沿它们原样传播、边界处靠镜像折回，而能量始终守恒。
