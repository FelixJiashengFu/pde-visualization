# 波动方程：d'Alembert 公式与特征线

**分类：**双曲型 · 波动与振动。一维波动方程 `u_tt = c²u_xx` 的精确解：行波分解、特征线上的依赖域与影响域、有限弦端点的镜像反射与能量守恒。

- [验证脚本说明](source/README.md)。

## 方程、区域和初边值条件

| 实验 | 区域与条件 | 解法 |
| --- | --- | --- |
| 一 · 行波分解 | `x∈ℝ`，`u(x,0)=φ`，`u_t(x,0)=ψ`；φ 为高斯/方块/三角，ψ 为无/高斯/方块 | `u = ½[φ(x−ct)+φ(x+ct)] + (1/2c)∫_{x−ct}^{x+ct} ψ` |
| 二 · 特征线 | 同实验一，点选 `(x₀,t₀)` | 依赖区间 `[x₀−ct₀, x₀+ct₀]`，初值支集的影响域楔形 |
| 三 · 有限弦 | `0<x<L=4`，`c=1`；两端固定 `u=0` 或两端自由 `u_x=0`；高斯位移脉冲或速度冲量 | 对初值做 2L 周期奇／偶延拓（镜像和）后用 d'Alembert 公式；能量 `E=½∫(u_t²+c²u_x²)` |

## 操作与读图

| 控件或图 | 含义 |
| --- | --- |
| φ、ψ、`c`、`t` | 实验一、二共用；`c ∈ [0.5,2]`，`t ∈ [0,4]`。 |
| 实验一 | 金线为 `u`；青、粉虚线为右行、左行半波；紫虚线为速度项；底部三角标出 `±ct`。 |
| 实验二左 | `x–t` 平面热图（橙正蓝负），青色三角为依赖域，灰虚线为初值支集的影响域边界；点击或拖动选点。 |
| 实验二右 | `t=0` 上的 φ（金）与 ψ（紫），青色带为依赖区间，紫色阴影是被积分的 ψ。读数把 `u(x₀,t₀)` 拆成 φ 端点项与 ψ 积分项。 |
| 实验三 | 金线为弦上的解，灰线为弦外镜像；右图为动能、势能、总能量随时间（`0–16`，两个周期）。 |

## 验证与范围

运行 `node source/verify.cjs`，共 12 项检查：初值条件、方程差分残差、ψ 原函数、方块冲量平台高度、固定端 `u=0`、自由端 `u_x=0`、`2L/c` 周期性、四种组合能量守恒（相对漂移 < 10⁻¹⁴）、固定端反射翻转、自由端反射不翻转、`u_t`/`u_x` 解析式与数值导数一致。

方块、三角初值给出弱解（跳跃沿特征线传播）；实验三只用光滑高斯，其镜像和在端点严格满足边界条件。页面已用无头 Chromium 在 `file://` 下截图检查（桌面与手机宽度，无脚本错误、无横向溢出）。
